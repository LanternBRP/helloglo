## Current conclusion

The build defines **29 preferred canonical URLs** and four compatibility aliases. Each preferred route has a unique title, one H1, and a self-referencing canonical tag in the generated page file. The tables below show the exact wording now in the build so URL terms, page titles, and H1 copy can be reviewed together.[1]

> **Important staging note:** The updated sitemap is published, but the Manus staging host currently returns the homepage initial HTML for clean nested URLs such as `/recruiter-os/`. The correct route-specific HTML is present at each explicit `/index.html` file. Manus documents a separate built-in SEO prerendering setting for search-engine bots; that setting or an equivalent clean-route rewrite still needs to be enabled before the SEMrush issue is considered fully resolved.[2]

## Naming decisions worth confirming

The visible product name **The Desk** currently keeps `/recruiter-os/` as its canonical URL. **Client Room** keeps `/client-portal/`, and **Candidate Room** keeps `/candidate-portal/`. The visible **Built For** overview keeps `/who-we-serve/`. Healthcare also uses `/who-we-serve/healthcare-staffing/`, while the other four vertical pages use `/built-for/.../`. These paths are technically valid, but they are the places where the visible wording and URL wording intentionally differ.
